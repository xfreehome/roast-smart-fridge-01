Entry for the [Roast the Smart Fridge: One Line, Best Laugh Wins](https://make.fun/bounty/u-kiencx-roast-the-smart-fridge-one-line-best-laugh-b354d6c9) bounty on [make.fun](https://make.fun): a program that writes one roast line of a smart fridge, at most 160 characters.

## The entry

> My smart fridge sends me a notification that the milk expired — it watched it die in 4K and did nothing, like a lifeguard who can't swim.

## Run

```sh
node main.ts   # writes /output/entry.txt (137 characters)
```

Requires Node 22.18+ (TypeScript runs as-is).
